## 4. Temporal Buffering & Window Progression Contract

The `EnergyMLBackendAdapter` maintains an internal 24-hour ring buffer per station. The exact state transition logic is audited below:

```text
Incoming Hourly Stream:
  t01 .. t23  → status: INSUFFICIENT_HISTORY (available: 1..23, prediction: null)
  t24         → status: PREDICTION_AVAILABLE   (available: 24,    prediction: UnifiedPrediction)
  t25 .. tN   → status: PREDICTION_AVAILABLE   (available: 24,    prediction over [tN-23, tN])
```

### Exact State Transition Semantics:
1. **$0 \le N \le 23$ Hourly Records:** Returns `AdapterResponse(status="INSUFFICIENT_HISTORY", available_history=N, prediction=None)`. Neural inference is bypassed; no synthetic data is fabricated.
2. **$N = 24$ Hourly Records:** Returns `AdapterResponse(status="PREDICTION_AVAILABLE", available_history=24, prediction=UnifiedPrediction.to_dict())`.
3. **$N > 24$ Records (Sliding Window):** Ring buffer discards record $t-24$ and retains latest 24 contiguous records $[t-23, t]$. Returns `PREDICTION_AVAILABLE`.
4. **Timeline Gap ($\Delta t > 1\,\text{h}$):** When a gap occurs (e.g. communications dropout), the adapter safely resets the contiguous buffer counter. The next prediction is emitted only after 24 *new contiguous hourly records* are received.
5. **Duplicate Timestamp ($\Delta t = 0\,\text{s}$):** Deterministically raises `ValueError("Duplicate telemetry timestamp ...")`. Previous buffer history remains uncorrupted.
6. **Out-of-Order Timestamp ($\Delta t < 0\,\text{s}$):** Deterministically raises `ValueError("Out-of-order telemetry timestamp ...")`. Buffer remains uncorrupted.

## 6. Provenance & Synthetic Data Boundary

The unified prediction payload strictly preserves all four provenance fields:
- `provenance.source`: `"SYNTHETIC_POLARIX_OPERATIONAL_DATA"`
- `provenance.model_status`: `"CANDIDATE"`
- `provenance.calibration_reference`: `"Australian Antarctic Data Centre (AADC CC BY 4.0) & NCPOR Meteorological Archives"`
- `provenance.disclaimer`: `"Validated on synthetic Polarix operational microgrid telemetry. Not validated on real classified station SCADA telemetry."`

### Provenance Distinctions:
1. **Open-Access Reference:** Australian Antarctic Data Centre (AADC) macroscopic 23-year historical monthly electricity dataset provides Antarctic seasonal load validation.
2. **Meteorological Envelope:** NCPOR / NPDC Indian Antarctic station archives define the physical temperature, wind speed, and pressure distributions.
3. **Operational Telemetry:** High-frequency sub-hourly microgrid operational telemetry is synthetic due to government data classification. It must never be represented as real station SCADA logs.

## 7. Backend Failure-Mode & Operational Response Matrix

| Telemetry / Stream Condition | ML Adapter Response | Backend Expected Action |
|:---|:---|:---|
| **$N < 24$ Contiguous Hours** | `status: "INSUFFICIENT_HISTORY"` (`prediction: null`) | Log buffering progress ($N/24$), await next hourly record |
| **$N = 24$ Contiguous Hours** | `status: "PREDICTION_AVAILABLE"` (`prediction: dict`) | Persist prediction to database, execute dispatch rules |
| **Timeline Gap ($\Delta t > 1\,\text{h}$)** | `status: "INSUFFICIENT_HISTORY"` (contiguous reset) | Log telemetry gap event, resume buffering new sequence |
| **Duplicate Timestamp** | Raises `ValueError("Duplicate telemetry ...")` | Log warning, discard duplicate packet, do not insert duplicate DB row |
| **Out-of-Order Timestamp** | Raises `ValueError("Out-of-order ...")` | Discard packet or route to historical reconciliation queue |
| **Station Code `"BHR"`** | Raises `ValueError("Invalid station_id 'BHR'...")` | Normalize `"BHR"` to `"BRT"` in backend gateway before ingestion |
| **`NaN` or `Inf` in Float Fields** | Raises `ValueError("... contains NaN or infinite")` | Reject telemetry packet, flag station sensor communication error |
| **Physical Value Out of Range** | Raises `ValueError("... out of physical bounds")` | Reject packet or flag critical telemetry fault |
| **Malformed Schema / Missing Key** | Raises `ValueError("Missing required ...")` | Reject payload, return HTTP 422 Unprocessable Entity |
